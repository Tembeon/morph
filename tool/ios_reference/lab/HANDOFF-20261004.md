EVIDENCE means acquisition checks passed with no fidelity gates declared.
It does not mean native match. REVIEW / exit 2 means failed checks or
incomplete evidence. Missing films, properties or tracks are not passes.
Every gesture film window needs at least 80% coverage through release plus
500 ms. Local complete windows do not override failed global acquisition.
Markers prevent still-screen timestamp compression and associate films with
telemetry, but physical display latency is not directly timestamped.

actual gesture protocols; use LabApp(builders:) or LabApp(child:) on Flutter,

logic but cannot substitute for a device film.

For optics use scenarios/glass-optics.json and matrix to generate light/dark

no fitter writes values into production. Unknown or unidentifiable values
remain measurement requests, not hand-tuned constants.

## Native layer interpretation and renderer hypothesis

The earlier assumption that native simply removes all separate submenu
material at the 12 ms close kick was wrong. Original SDF elements leave,
but matched carrier copies remain. Source rec-mm-sub-tap.jsonl survives in
../recordings/device-menumotion/ and device-menumotion2/. Check the source
hash against card-material-copy.json before selecting a recording.

Logical close: 127030.068686125. Copied key-fill CASDFLayer 175 follows
(width - 50) / 200 from 250 pt width toward 50 pt. Copied element 174 keeps
250 x 208 local bounds and eight local radii of 32; ancestor carrier changes
its world geometry. Fit response ~0.350055, damping ~0.849935,
delay 0.01969054, geometry residual ~0.016 pt. Production defaults remain
0.35/0.85 and 0.015 delay; the new fixture test supplies its measured delay.
Three copied-opacity samples have about one-frame discrepancy, RMS ~0.0126,
max .06. Do not fit those anomalies into another invented physics channel.
Native retains both original header material and fading copies; root common
SDF geometry and card carrier are not identical objects.

Shadow fit: native straight-side/bottom profiles excluding 3 pt around the
contour, encoded SDR red channel on #F2F2F7. Gaussian half-plane alpha
0.11878094, sigma 16.54573548 pt, y-offset 8.1093498 pt, RMS 0.2726393
encoded gray. Rounded Flutter alpha byte 30, blur radius 28, offset 8 gives
independent native holdout RMS 0.2882839. This is a light appearance fit,
not proof of final GPU rendering, rounded-corner behavior or dark material.
Fit script was lost in /tmp; fixture retains the samples and model metadata.

Unproven next hypothesis: geometry textures encode data in all RGBA channels,
including alpha; alpha is not ordinary coverage. The GPU data passes do not
explicitly disable blending. If default blending is src-over, reused render
textures/loadAction dontCare can corrupt low-alpha distance data and remove
the exterior contour. Default state has not been established and no A/B
verification exists. Inspect renderer geometry/material passes and Flutter
GPU API defaults; capture rawUnmodified edge pixels with a minimal diagnostic.
Only then consider explicit setColorBlendEnable(false) for data passes.
Do not introduce a painted rim to conceal an unexplained renderer failure.

Other candidates: retained ancestor clips, geometry texture UV capacity,
exterior support/feather, filter bounds and composition/opacity ownership.
The existing _Reach margin is 24; new body shadows are painted outside the
layer. Increasing padding blindly does not establish a clipping diagnosis.
