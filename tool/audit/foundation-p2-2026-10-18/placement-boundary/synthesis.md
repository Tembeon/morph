# Synthesis: operation boundary, one admitted snapshot

## Problem

Native functional reuse supports a fresh placement decision on each opening, while optical return remains unknown. Separate the existing admission knowledge without relaxing any active retirement, callback or paint outcome.

## Usage

Caller remains ProbeMenuSource.measured(button: localButton, menuBuilder: buildMenu). The state captures/validates source facts and calls _admitMenuPlacement(view, bounds, overlayMap, button: button, minimum: minimum). Session still retains one complete _MenuGeometry. Measured source painter calls session.readSourcePaintGeometry() inside the existing source-only guard, then tests owner; fixed/route painters do not call it.

## Shape

The placement operation owns all physical safe/IME projection, actual-overlay intersection, minimum tuning fit and full source containment, yielding either one admitted rectangle or null. Source state owns framework attachment/transform/finite-shape capture. available/padding are not stored twice. _MenuGeometry.agrees remains the single combined predicate; current active policy is deliberately unchanged. The session method owns the existing double paint fence: capture admitted snapshot, checkGeometry, then fresh full agreement under strict idle before allowing carried contour paint. It is effectful and therefore a method, not a getter.

## Synthesis decision

Two inherited-model attempts, not multi-model evidence. A offers nested validated endpoint/admission values; B initially independently converged on composition and then, on an explicit request for a structurally distinct alternative, produced operation-oriented isolation. Both completed artifacts were read before judging. Fresh judge and parent score A14/15 and B14/15: A3/3/2/3/3, B3/3/3/2/3 against frame.md. B wins tie on smaller current interface and no extra allocated value needed by an independent endpoint consumer. Parent agrees.

Graft/refinement from cross-judge: use effectful readSourcePaintGeometry method rather than B getter, under the unchanged measured/restingButton guard. Omit B's optional _sameEndpoint helper: no independent caller yet, and the complete agreement remains authoritative. No candidate dropout or rejected judge rerun. No public policy switch, observer, new mutable epoch or ticker.

## Tradeoffs and alternatives

We accept keeping one combined validity predicate until optical evidence justifies a new policy, in exchange for unchanged observable behavior. A's deeper endpoint type is viable once an independent consumer exists; it currently adds navigation/allocation without changing any capability. Separate mutable source/placement snapshots lose one authority and invite callback reentry version bugs. No active rebase/relayout is introduced.

## Open gate and verification

This is a calculation/paint ownership boundary, not a new endpoint-validity policy. Optical landing, moving source, hidden hold/reservation native parity and P3 remain open. Existing62 tests, both64-frame contour oracles, full example and emitted replay/timing/scene records must remain unchanged. No new mirror tests are needed for this behavior-neutral relocation. If those results diverge, investigate/scrap instead of changing expectations.
