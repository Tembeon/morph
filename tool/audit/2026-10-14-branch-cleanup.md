## Последующая уборка remote

По отдельному запросу владельца удалены 18 remote-веток. Открытых PR не
было. `exp/navigation-defaults` уже входит в `wip`; остальные 17 веток
сохранены на origin в тегах `archive/2026-10-14/<исходное имя ветки>`.
Каждый тег указывает на исходный SHA соответствующей ветки, сохраняя её
историю. Создание тегов и удаление веток выполнены одним atomic push с
проверкой ожидаемых SHA; после операции refs проверены повторно.

На origin остались `main` и `wip/measured-liquid-glass`. Локальные
исследовательские ветки сохранены; ссылки на удалённые upstream сняты.
Эти архивные теги не являются версиями или релизами пакета.

Например, восстановить рабочую ветку эксперимента можно так:

```sh
git switch -c recovered/glyph-atlas \
  archive/2026-10-14/codex/exp-glyph-atlas
```

Карта исходных SHA, удалённых remote-веток и архивных тегов:
`.git/cleanup/2026-10-14/remote-cleanup-result.json`.
